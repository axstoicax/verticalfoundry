# VerticalFoundry v5.5 — Founder Story + Etsy FAQ Hub

New: `/store/` and 37 general FAQs in six categories. Distinct from `/products/`, which now contains an individual product catalog fed by `app/product-catalog.mjs`. The catalog is intentionally empty until real Etsy listing data exists. When adding a real listing to the array, provide all required fields and valid product FAQ entries; only use genuine prices and Etsy listing URLs.

Source of FAQ: Owner-supplied current Etsy Shop About/FAQ PDF, expanded editorially with careful caveats. Support, refunds and buyer rights remain subject to actual product terms, Etsy rules, and applicable law.

Run: `npm install`, `npm run validate:logos`, `npm run validate:site`, `npm run validate:seo`, `npm run validate:discovery`, `npm run build`.
